# CampusConnect

## About the Project

CampusConnect is a student networking platform developed
as part of the Data Structures and Algorithms mini-project
at Chanakya University.

The platform enables students to discover peers, establish
connections, share posts and interact with their campus
community.

## Features

- Student registration and authentication
- Password hashing
- Student profile creation and viewing
- Connection requests and invitations
- Accept, reject and cancel connection requests
- Mutual connections
- Shortest connection paths
- Student recommendations
- Live search suggestions
- Text posts, likes and comments
- Newest-first personalized feed
- Persistent SQLite storage

## Data Structures and Algorithms

- Graphs
- Adjacency Lists
- Dictionaries
- Sets
- Queues
- Breadth-First Search
- Searching Algorithms
- Sorting Algorithms

Graph computations are performed in Python using
in-memory data structures. SQLite is used for persistent
data storage.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## How to Run the Project

Click on the link:
https://unwashedconcern.pythonanywhere.com
Register a student account to explore the application.

## Academic Purpose

This project demonstrates the practical application of
data structures and algorithms in a real-world student
social networking platform.
